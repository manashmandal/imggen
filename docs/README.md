# imggen Docs

This folder contains extended documentation that complements the main README.

## Supported Image Models

- `gpt-image-1.5` (default)
- `gpt-image-1`
- `gpt-image-1-mini` — same capabilities as gpt-image-1, 50-70% cheaper
- `dall-e-3`
- `dall-e-2`

> **Note:** Sora video generation is shutting down September 24, 2026. See the [deprecation notice](https://help.openai.com/en/articles/20001152-what-to-know-about-the-sora-discontinuation).
